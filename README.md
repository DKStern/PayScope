# PayScope

PayScope помогает сравнить, сколько нужно зарабатывать в России по трудовому договору, в качестве ИП или самозанятого, чтобы получать желаемую сумму на руки.

Укажите желаемый доход в месяц. Калькулятор покажет, какую зарплату до налога или выручку нужно получать, и рассчитает почасовую ставку. При работе на себя можно учесть резерв на отпуск, больничные и добровольные пенсионные взносы.
